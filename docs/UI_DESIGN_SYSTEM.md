# 界面设计约定

采用 macOS 资料管理工具式布局：中性侧栏、安静的白色/深灰内容表面、细分隔线、紧凑工具栏、原生 select 与分段按钮。酒红色用于当前导航、筛选状态和主要交互，不给每块分析染色。

- `styles/tokens.css` 为颜色、间距、圆角、控件高度入口。间距以 4/8px 为基础，桌面控件 36px、手机触控 44px。
- 字体为 `-apple-system, BlinkMacSystemFont, system-ui`，提供中日文系统字体回退；不下载 Apple 字体。
- 数字使用 tabular numerals；表格奖金右对齐，单位放表头。马名主次分明，主名保持日文原值。
- 侧栏宽 208px，折叠 64px。1000px 以下变成临时导航；筛选始终按需打开，避免同时占用两条侧栏。
- 紧凑模式显示六列；详细模式保留所有原列和生涯战绩，在内部横向滚动。640px 以下使用卡片，两种密度保留同一详情入口。
- 表格限制在视窗内滚动，表头、详细模式首列固定；分析表、赛果表各自保留滚动容器。
- 主内容明暗层次均使用 token；不使用纯黑大块。图表世代/牝系/等级语义色不随主题重新定义。
- 所有新按钮均有文本或 accessible name；排序使用 `aria-sort`，结果使用 status 区域，行内使用真正按钮而非把整行改成按钮。
- 详情与筛选打开时背景不可交互，Tab 保持在面板内，Escape 关闭并恢复触发器焦点。Cmd/Ctrl+K 聚焦主搜索。
- `prefers-reduced-motion` 禁用非必要动画与过渡。主题刷新同步主图和放大图。

CSS 按职责修改原规则，避免在根样式末尾反复追加补丁；只有公共基础规则放 foundations。旧分析样式中仍有历史领域布局，后续修改相应部分时逐项收敛，不删除未经验证的规则。
