## 指标审计

- 当前 726 匹，449 匹生涯至少一胜，0 匹缺少可识别胜场。`populationGroups()` 仍读取生涯摘要的数字 +「勝」，已知零胜与未知保持区分；未知保留于总产驹分母，不推断为未胜。用含空值、未知文本、零胜、多胜的测试覆盖未来资料缺漏。
- 工作区统一“已确认胜马比例”；重赏马为最高成就 G1/G2/G3 的独立马匹 / 全组产驹。按世代、性别筛选的结果及下钻马匹集合不变。
- Profile 的场数为全部收录记录；胜场、前三与比例只按正整数正式名次。标题领衔 19 场中 18 场有效，自由岛 12 场中 11 场有效。取消或未知不补零；年度、场地、距离分组及恢复全部记录通过既有测试。
- 同龄比较继续使用已有累计胜场与每100匹值，排除未完整结束的年龄年度；AEI/CPI、AWD 与 Dosage 计算未改。
