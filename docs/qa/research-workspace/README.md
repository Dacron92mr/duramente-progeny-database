## 可核对的用户路径

1. 390/430px 手机地图：选择区域／体系 → 实际点击图上单场标记 → 看到场名、出赛、胜场、胜率、前三率与分母 → 打开对应独立产驹 → 打开 Profile。另验证拖动平移、放大、重置和列表切换。
2. 从“同龄世代”选择 5 岁末：2022 世代在 2026 截点不展示；点选图形进入比较 A，选择 B，然后打开该世代产驹。
3. 血统／生产限定 2019 世代、牝马、最低样本量：比较组 n 与跳转后列表总数一致；筛选保存在 URL 中。
4. Titleholder（有繁殖）与 Liberty Island（无繁殖）：完整原始赛果数量不变；点选场地后筛出该组，再恢复全部记录；母父、牝系、牧场跳转关闭详情并显示正确筛选。
5. 已核实同母关系：マリアイリダータ（47）→ ドゥラエレーデ（9），通过 netkeiba ID 对齐本站身份，不按马名猜测关系。

## 验证结果

- 18 项 Node 测试通过，覆盖来源不变、有效名次、分母、同龄截断、交集群体 ID、地图聚合和赛场索引数值对账。
- 30 项 Python 测试与 6 个既有图表／数据校验脚本通过。
- 通用浏览器 26 组、完整资料 8 组、研究探索 13 条功能路径通过；无 JavaScript 运行错误。
- 390/430px 地图两主题；390/1440px 研究比较；390/768/1280/1440px 列表；无意外页面横向溢出。
- 人工检查截图：主次马名、紧凑筛选、等级／所属、地图聚合标签、分母、两栏／三栏 Profile 和原始赛果可读。
- 原始来源和已有聚合数据无修改；新增的 `racecourse_population.json` 按原规则生成并逐场对账。

## 已知限制

- 测试为桌面 Chromium 的手机宽度与实际鼠标／键盘交互，不是实体 iOS/Android 触屏测试；双指缩放能力来自 ECharts roam，尚未在实体设备验证。
- 同一规模和比例的散点会重合，使用完整的 A/B 选择器访问每个组；不通过随机抖动改变数值位置。
- A/B、地图区域和选中场地是本页临时状态；下钻的产驹筛选与 Profile URL 可分享。
- 地图只显示已有坐标覆盖的日本 JRA/NAR 场地；海外保留在下方统计。聚合标记表示邻近位置的集合，非新地理点；区域定义用于浏览，不是新的赛事分类。
- 单马统计按当前原始记录计算，有名次的分母与官方生涯摘要可能不同。未实现缺乏可靠证据的“赛事级别晋升”或表现预测。
- 六大母父系、已有统计方法及人工维护数据保持原样。新增工作区不提供因果解释或显著性结论。
