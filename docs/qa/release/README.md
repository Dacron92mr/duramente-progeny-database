## Safari 验证范围

本机 Safari WebDriver 因未启用“允许远程自动化”而无法创建会话，没有修改该设置。已使用 Playwright WebKit 26.5 完成完整桌面/窄屏回归及 iPhone 触控模拟；不能据此声称实体 iPhone 或已安装 Safari 应用验收通过。建议合并前由使用者在实际 Safari/iPhone 做一次照片、抽屉滚动、外链与地图手势复核。

复跑：`npm test`、Python `unittest`、`scripts/verify_*`；浏览器使用 `test:browser`、`test:profile`、`test:research`、`test:content`。设置 `TEST_BROWSER=webkit` 切换引擎，`test:mobile` 专门执行 WebKit 触控模拟。环境准备见 [开发说明](../../DEVELOPMENT.md)。
