# Duramente Progeny Database

**ドゥラメンテ（大鸣大放）产驹数据库**

一个围绕日本种牡马 **ドゥラメンテ（Duramente）** 建立的专题赛马数据库，用于浏览其产驹资料、比赛成绩、血统结构与繁育表现。

目前收录 **2018–2022 年出生的 726 匹产驹**，并持续更新现役马的比赛记录和相关统计。

**在线浏览：**
https://dacron92mr.github.io/duramente-progeny-database/

---

## 可以在这里查什么？

### 产驹资料

可以按出生年、性别、所属、练马师、生产牧场、母父、母父系、牝系、战绩等级等条件筛选产驹。

每匹马的详情页包括：

* 马名、英文名及香港译名
* 出生年、性别、毛色与所属
* 母、母父、母父系与牝系
* 马主、练马师与生产牧场
* 生涯战绩、奖金与主要胜鞍
* 完整比赛记录
* 部分退役马的种牡马或繁殖母马记录

## 数据分析

网站除了单马资料，也从多个角度整理ドゥラメンテ的种牡马表现。

### Stallion Performance

**种牡马表现**

观察不同出生世代的奖金、胜马、重赏成绩、成长曲线与平均胜距，并追踪ドゥラメンテ产驹成绩随时间的发展。

### Pedigree Analysis

**血统分析**

包括：

* 母父及母父系表现
* 牝系分析
* 五代血统表内 Cross
* DP / DI / CD（Dosage Theory）
* 血统结构与实际比赛距离表现的比较

部分分析参考传统 Thoroughbred breeding theory，用实际赛场成绩与血统结构从不同角度观察产驹特征。

### Production & Breeding

**生产与繁殖**

分析主要生产牧场、繁殖母马、母龄、胎次、配种月份与出生月份等信息。

### Racecourse Analysis

**赛马场分析**

比较产驹在 JRA、NAR 及海外不同赛马场的出赛、胜场、胜率、前三率、场地和距离表现。

## 数据范围

当前数据库固定收录ドゥラメンテ **2018–2022 五个出生世代，共 726 匹产驹**。

网站不会因为自动更新而自行增加或删除收录马匹，因此不同时间查看时，研究样本保持一致。

现役马的比赛记录、生涯成绩与奖金会继续更新；部分血统、繁殖和历史资料属于相对稳定的数据，不需要按周变化。

---

## 数据更新

现役产驹资料通过 GitHub Actions 定期检查公开来源。

* **netkeiba**：每周进行一次全库更新
* **JBIS**：按照限速要求分批检查，在一周内完成一轮
* 更新后会重新计算与比赛成绩有关的统计和图表
* 新数据通过校验后才会发布到网站
* 如果来源暂时无法访问或数据异常，原有记录会保留

因此网站属于 **定期更新的静态数据库**，并非实时赛果服务。

---

## 数据来源

资料主要整理自公开赛马数据库及官方资料，包括：

* netkeiba
* JBIS
* Japan Stud Book
* 香港赛马会公开资料
* 其他公开赛马及血统资料

不同来源的奖金、战绩分类和登记口径可能存在差异。本网站会尽量保留来源信息，并在统计时统一口径。

---

## 关于统计结果

网站中的胜马率、重赏马率、平均奖金、平均胜距、Cross、Dosage 等指标主要用于描述和比较样本。

血统组合、母父系、牝系、母龄或 Cross 与比赛成绩之间的关系可能受到样本量、繁殖母马质量、训练、赛程和其他因素影响，因此这些结果适合作为探索性资料，不应视为因果结论。

本数据库也不提供投注建议。

---

## About this project

这个项目最初用于整理和研究ドゥラメンテ产驹，并逐步扩展为包含比赛记录、血统、繁殖和种牡马统计的专题数据库。

网站采用静态数据结构，通过 GitHub Pages 发布，不需要注册或登录即可浏览。

数据与页面仍在持续整理中。如果发现明显的数据错误，可以通过 GitHub Issues 提出。
