# ドゥラメンテ产驹数据库

这是一个用于浏览大鸣大放（Duramente / ドゥラメンテ）产驹资料的静态网页数据库。

公开访问地址：

https://dacron92mr.github.io/duramente-progeny-database/

## 网站内容

目前收录 2018-2022 年出生的 726 匹大鸣大放产驹。页面可以查看：

- 马名、英文名与香港译名
- 生年、性别、毛色、所属、练马师、生产牧场
- 母名、母父、母父大系统、牝系编号
- 奖金、主要胜鞍、战绩等级
- 单匹马的完整比赛记录
- 部分退役马的种马或繁殖牝马记录
- 种牡马成绩、母父分析、世代比较、距离与场地拆分
- 修正后的 Cross 祖先 / 祖先+Cross形式 / 结构层分析
- 牧场分析与赛马场胜率、连对率、前三率分析

## 使用方式

左侧筛选栏可以按生年、性别、毛色、所属、练马师、最高战绩、繁殖记录、母父个体、母父系和牝系筛选。

搜索栏支持输入日文马名、英文名、香港译名、母名、母父、练马师或牧场名。点击表格中的任意一匹马，可以打开详细资料页。

顶部导航可以切换到“種牡馬成績”“母父分析”“血統分析”“牧場分析”“競馬場分析”和“データ・方法”。分析页中的统计会同时显示分子、分母和样本量，避免只看百分比。

Cross 统计使用独立产驹数口径；同一匹马可以同时进入多个 Cross 组，所以各组奖金不能相加当作总奖金。赛次奖金字段目前覆盖率不足，网站暂时不展示赛次层面的奖金汇总。

## 数据说明

本数据库整理自公开赛马资料，主要用于个人兴趣研究和浏览展示。数据来源包括 netkeiba、JBIS、香港赛马会公开资料与 Japan Stud Book 公开页面等。

本仓库发布的是静态快照版本，所有资料已经导出为 JSON 文件，网页本身不连接后台服务器，也不会实时抓取数据。若原始数据库后续更新，需要重新导出并发布新版。

## 技术说明

这个站点是纯静态网页：

- `index.html`：页面结构
- `style.css`：页面样式
- `app.js`：搜索、筛选、排序、详情页交互
- `data/`：导出的马匹列表、详情、战绩、繁殖记录和分析指标 JSON

因为是 GitHub Pages 静态站点，朋友打开链接即可使用，不需要安装 Python、SQLite 或任何本地环境。

## 可修改 JSON 数据

仓库中的 JSON 已统一使用 UTF-8 和两空格缩进，方便直接在 GitHub 网页版 VS Code（`github.dev`）中阅读和修改。

打开 JSON 文件后可以直接编辑字段。仓库自带的 `.vscode/settings.json` 会在保存时自动格式化 JSON。如果格式没有自动变化，可以打开命令面板，执行 `Format Document`。

在本地批量检查 JSON 格式：

```bash
python3 scripts/format_json.py --check
```

在本地批量格式化 `data/` 下的所有 JSON：

```bash
python3 scripts/format_json.py
```

也可以只格式化一个文件或目录：

```bash
python3 scripts/format_json.py data/summary.json
python3 scripts/format_json.py data/analytics
```

修改马匹数据时请注意：`data/horses.json` 是列表资料，`data/horses/{id}.json` 是单匹详情，`data/summary.json` 保存总数和筛选选项。新增或删除马匹时，这些文件需要保持一致。

## 注意

资料仅供参考与交流，不建议用于商业用途或作为投注依据。

## 图表派生数据

奖金集中度和获胜距离分布从现有马匹奖金及草地、泥地获胜记录生成，不修改原始记录。更新原始资料后执行：

```sh
python3 scripts/build_chart_insights.py
python3 scripts/verify_chart_insights.py
```

同龄累计胜场仅纳入数据最后更新年份之前已完整经历所选年龄年度的世代；每100匹的分母为该世代全部收录产驹。桑基图按“生产牧场 → 登记俱乐部马主”展示来源关系，不推断直接交易。

## 后台每周同步

部署状态：工作流权限已完成授权，定时任务随本次提交启用；每次运行结果见仓库 Actions。

GitHub Actions 的 `Weekly data sync` 每周一香港时间 **08:23** 启动（UTC 00:23，平台繁忙时可能延迟），页面没有同步入口或管理界面。

- netkeiba：按已登记 ID 更新公开生涯奖金、通算战绩、主要胜鞍和赛果；按表头解析，至少间隔4秒。无出赛记录的马跳过赛果请求。
- JBIS：遵守公开 robots.txt 的600秒间隔，每周一开启新周期，每6小时串行处理最多30匹的总奖金；游标保存在 `.github/sync/state.json`。完成当周名单后自动空跑跳过；正常情况下约6天完成一轮，不是秒级实时接口。
- 数据先在临时副本中更新、重建统计并校验；身份错误、历史记录减少、奖金异常下降、验证码、403或429会保留原资料；整批成功率低于90%不发布。
- 保留原马匹 ID、其他来源赛果，以及单独维护的血统、配种市场和外部种牡马排名。此任务不会替代这些来源的独立更新流程。不会自动删除马匹或扩张收录名单。
- 诊断报告保留在 Actions 的运行附件中30天，不放到网站。检查任务随提交自动运行。
- 校验通过后由仓库自带的 `GITHUB_TOKEN` 提交数据并请求原 GitHub Pages 构建，不需要个人账号密码。若仓库策略禁止 Actions 写入或构建，任务会失败并保留错误记录，不会伪报成功。

手动运行时默认只预览；确认需要实际写回时勾选 Apply。本地只读演练：

```sh
python3 scripts/weekly_sync.py --limit 1 --jbis-limit 1 --report /tmp/sync-report.json
python3 -m unittest discover -s scripts/tests -v
```

长期无人提交的公开仓库可能被 GitHub 暂停定时任务，需从 Actions 重新启用。JBIS队列使用与主同步相同的互斥组，避免写入冲突；netkeiba承担每周全库主更新。`数据与方法` 页面已从公开导航及路由中移除，内部统计说明保留在数据文件和本说明中。

## 图表颜色约定

世代代表色固定为 2018 深酒红、2019 玫红、2020 浅红、2021 橙色、2022 黄色，集中定义于 `chart-colors.js`。世代堆叠系列、成长曲线和单世代柱形保持一致。成就热力图按各世代颜色的深浅表示比例，数值仍使用共同的0–100%口径；比较不同世代时以标注百分比为准。

牝系按数字主号沿柔和彩虹色序排列，字母分支只小幅改变亮度；筛选或重新排序不会改变同一牝系的颜色。A/B/C编号独立保留。性别和成就分类继续使用各自图例，在牝系轴标签旁添加同号颜色标记，避免混淆两种含义。

简单折线直接标数，密集多系列通过悬浮查看。图表配色校验：`node scripts/verify_chart_colors.cjs`。
